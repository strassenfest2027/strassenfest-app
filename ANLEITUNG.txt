STRASSENFEST PWA V1

Das ist eine schnelle vorgeschaltete PWA-Hülle für deine bestehende Google-Apps-Script-App.

Vorteile:
- Startseite erscheint sofort.
- Ladebildschirm ist sofort sichtbar.
- Die bestehende Straßenfest-App wird anschließend im Hintergrund geladen.
- Kann am Handy zum Startbildschirm hinzugefügt werden.
- Keine Änderungen an deiner funktionierenden Apps-Script-App nötig.

Wichtig:
1. Öffne config.js.
2. Ersetze:
   https://DEINE-APP-URL
   durch deinen aktuellen Apps-Script-Web-App-Link.
3. Lade alle Dateien auf ein schnelles Hosting:
   - GitHub Pages
   - Netlify
   - Cloudflare Pages
   - eigener Webspace
4. Den Nachbarn gibst du künftig den Link zu dieser PWA, nicht mehr direkt den Apps-Script-Link.

Dateien:
- index.html
- config.js
- manifest.json
- sw.js
- icon.svg
