STRASSENFEST V9.2 – GITHUB DESKTOP DIREKT-UPDATE

Diese ZIP ist absichtlich anders aufgebaut als vorher:

Alle Dateien liegen direkt auf oberster Ebene.
Es gibt KEINEN zusätzlichen Ordner "github".

SO GEHT DAS UPDATE:

1. ZIP entpacken.
2. In GitHub Desktop auf "Show in Explorer" klicken.
3. Den kompletten Inhalt dieser ZIP in deinen lokalen Ordner
   "strassenfest-app" kopieren.
4. Vorhandene Dateien ersetzen.
5. GitHub Desktop öffnen.
6. Unten bei Summary z. B. eintragen:
   Update auf V9.2
7. "Commit to main" anklicken.
8. Danach oben "Push origin" anklicken.

Fertig.
